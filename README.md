# 20·5·1 — 一分钟讲明白

20 分钟研究，5 分钟准备，1 分钟讲明白。一个逼你把知识说出口的计时训练场。

灵感来自抖音上「20分钟研究 / 5分钟准备 / 1分钟呈现」的自我挑战：
画面挂倒计时，口播时实时记「卡壳 x1 / 口齿不清 x1」。这里把那套规则做成了网页。

## 它做什么

- 三段计时，自动流转：研究 → 准备 → 呈现，最后 10 秒变红
- 研究阶段记笔记；准备阶段提醒你别再查资料，只能整理已有的料
- 呈现阶段四个计数按钮：卡壳 / 口齿不清 / 跑题 / 嗯…那个（空格键 = 卡壳）
- 可选录音，结束后回放（音频只在浏览器内存里，不落盘不上传）
- 复盘页给失误分布条形图和一句判词，场次记录存 localStorage

## 技术

三个静态文件，没有构建步骤，没有依赖，没有后端，没有账号，没有埋点。
计时用 `setInterval`，提示音用 WebAudio 现场合成，录音用 `MediaRecorder`。

```
index.html
assets/style.css
assets/app.js
```

## 本地跑

```bash
python3 -m http.server 8899
# http://127.0.0.1:8899
```

录音需要 HTTPS 或 localhost 才能拿到麦克风权限。

## 部署

任何静态托管都行。Vercel：

```bash
vercel --prod
```

## 隐私

笔记、场次记录只写这台设备的 localStorage。录音是内存里的 blob，关掉页面就没了。
没有任何请求发往任何服务器。
